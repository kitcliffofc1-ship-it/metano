# Metano

Bot Discord multifungsi: moderation, economy, leveling, quest, dan auto-filter.

## Fitur

- **Moderation** — kick, ban, warn, timeout, purge
- **Economy** — balance, work, daily, shop, transfer
- **Leveling** — XP, rank, leaderboard
- **Quest** — auto-track quest tiap 2 jam
- **Auto-filter** — blokir kata sensitif otomatis

## Tech Stack

- Node.js + discord.js v14
- SQLite (sql.js)
- Hosting: Wispbyte
